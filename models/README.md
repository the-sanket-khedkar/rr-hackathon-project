# Models Directory

This directory originally contains trained machine learning models used in the project.

The model files are not included in this repository due to data confidentiality and size constraints.

## Notes

- Models were trained on proprietary hackathon dataset  
- This repository includes only the pipeline and structure  
- To run the project end-to-end, models need to be retrained using your own dataset  

## Usage

You can:
- Train new models using the provided scripts  
- Replace this directory with your own trained models  
- Modify the pipeline to work with custom inputs  

---

This setup is intentional to keep the repository clean, secure, and reproducible.

This approach reflects standard industry practices for handling sensitive data and model artifacts.
